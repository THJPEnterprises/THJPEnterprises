# THJP Enterprises — website (2026 redesign)

Static site for GitHub Pages. No frameworks, no build step needed to publish.

## Structure
```
index.html            Home
404.html              Not-found page (GitHub Pages serves this automatically)
pages/about.html      About
pages/brands.html     Brand portfolio (Vinnie's Oil Australia, Arborean, brand partnerships)
pages/products.html   Trade range
pages/contact.html    Trade enquiry form (?type=retailer|brand|wholesale|general preselects the enquiry type)
css/style.css         All styling — colours/fonts are tokens at the top under :root
js/shared.js          Header, mobile menu, scroll reveals, counters, contact form
CNAME                 Custom domain (thjpenterprises.com)
sitemap.xml, robots.txt  Search-engine files (regenerated by the build script)
_build/               Optional page generator (ignored by GitHub Pages)
```

## Deploying
Replace the contents of the existing GitHub Pages repository with this folder's contents
(keep your existing `images/` folder), commit, and push. Pages updates within a minute or two.

## Editing
- **Quick text edits:** edit the HTML files directly.
- **Header/footer or site-wide changes:** edit `_build/build.py` (shared header/footer) or a page body in
  `_build/bodies/`, then run `python3 _build/build.py` to regenerate every page.
- **Colours:** change the `:root` tokens in `css/style.css` (`--signal` is the orange accent, `--ink` the dark).

## Images
Vinnie's Oil photos are optimised copies (1400px, ~250–400 KB) in `images/web/`. The THJP badge is in
`images/thjp-badge-*.png`. The Arborean workshop photo is loaded from arborean.com.au. If any image fails,
its card falls back to a styled placeholder.

## Contact form
Enquiries are sent straight to info@thjpenterprises.com via FormSubmit (free, no account).
**One-time activation:** submit a test enquiry on the live site, then click "Activate Form" in the email
FormSubmit sends to info@thjpenterprises.com. Each enquiry arrives as a formatted table; the sender gets an
automatic confirmation; a hidden honeypot field filters basic spam bots.
